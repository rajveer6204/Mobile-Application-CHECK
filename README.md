## ⚙️ How to Run the Projects

1. Install Android Studio.
2. Clone or download this repository.
3. Extract the downloaded ZIP if necessary.
4. Open Android Studio.
5. Select **Open** and choose an individual project folder.
6. Wait for Gradle Sync to complete.
7. Connect an Android device or start an emulator.
8. Click the **Run ▶** button.

**Note:** Each project has its own Gradle configuration. Open the individual project folder containing its `settings.gradle.kts` file.
